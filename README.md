# CFB Yardage Numbers (Stream D)

A standalone weekly page of team **rushing-yards** numbers vs FanDuel's team rushing line,
for college football. Open `index.html` (published via GitHub Pages).

- Situational, hand-bet research lane — **not** an automated bet-model input.
- Our number: expected carries × expected yards per carry, opponent-adjusted, corrected for
  spread and total (sacks count against rushing). Weather is shown for context, not in the number.
- HTML only. No data files, no code, no secrets.
